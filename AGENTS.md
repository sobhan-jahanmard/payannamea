# Project guidance

For Telegram account, channel, content or integration work, read
`telegram/AGENTS.md` and use the user's saved format in
`telegram/channel-format.json`. Keep Telegram-specific files under `telegram/`.

For Instagram account or integration work, read `instagram/AGENTS.md` and the
current connection status in `instagram/connection.json`. Keep Instagram-specific
files under `instagram/`; verify authenticated identity before account changes.
