# Daneshyar University Research

Handle only the stored type `تحقیق دانشگاهی`. Produce a substantive course research report scaled to the assignment's quantity and learning context, with a direct answer to its question.

Use [daneshyar-order](../daneshyar-order/SKILL.md) for fetch, workspace,
continuation, tool invocation and publication boundaries. Read
[the shared ten-milestone document workflow](../daneshyar-order/references/documents.md),
[artifact contracts](../daneshyar-order/references/document-artifacts.md) and
[this type's guide](references/guide.md) before planning or drafting.

Complete the work in the current conversation. Announce and persist each actual
milestone. Read all supplied evidence and guidelines; use verified external
research appropriate to this assignment. Preserve existing validated work and
explicitly disclose missing essential data. Never invent sources or observations.

Use `order_tools.py` to prepare/extract, validate evidence and document candidates,
record honest content/source audits, build/render, inspect actual page images and
finalize the full editable Word/PDF plus first-half sample package. Include all
required companion reports. After completion and every revision, show the complete
current delivery using the main skill's fresh file-citation directives. For
requested revisions use [daneshyar-revise](../daneshyar-revise/SKILL.md); for an
explicit independent grade use [daneshyar-review](../daneshyar-review/SKILL.md).
