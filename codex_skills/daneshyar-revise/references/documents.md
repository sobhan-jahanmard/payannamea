# Revision branch for Word/PDF orders

Use the main revision skill's identity/review matching, unique baseline snapshot,
repair plan, acceptance checks and completion procedure. The type-specific skill
and shared document workflow determine the content and file contracts.

Snapshot the explicit current delivery files, final/deliverable_source.md,
planning/document_plan.json, planning/visual_plan.json,
planning/resolved_source_rules.md, extracted/university_rules.json,
research evidence/analysis/scripts/data, figure assets and current audit/state
files. Retain paths and hashes; do not recursively copy reviews/revisions.
Plan items identify affected sections/pages and files rather than slide numbers.

Repair the authoritative Markdown, evidence, analysis, figures or rules. A review
finding is a proposal to check against the actual order/source, never new evidence.
Verify new external sources when genuinely needed for authorized document research;
the presentation-only restriction on external academic material does not apply.
Preserve honest data gaps. No request to improve a grade authorizes fabricated
data, results, participants, citations or approvals. A proposal remains a proposal;
do not add allegedly completed experiments to satisfy a mistaken review.

Use validate rules --candidate when typography changes, then prepare/extract as
required by freshness checks. Revalidate evidence if its inputs change, followed
by validate document --candidate. Refresh content and source reviews using their
exact hashes and every plan section ID. Rebuild and render, including required
companions and first-half samples. Open every current page image and inspect the
native DOCX; record all image paths in the visual review. Regeneration of samples
is required even if a repair only changed the full file's pagination.

Complete each plan item's observable acceptance check against current outputs.
Finish with finalize/status, save the revision report and show all current full,
sample and companion files with fresh citations. Source edits alone do not prove
a visual repair. Author checks do not constitute a new independent grade; use
daneshyar-review only when regrading/review is requested. Publishing remains
subject to the main skill's existing authorization boundary.
