# Instagram — دانشیار

اکانت هدف: [@daneshyar.web](https://instagram.com/daneshyar.web)، از نوع Business
طبق تأیید کاربر. مجموعهٔ ۱۳ مهارت رایگان تولید محتوا نصب و برای Codex و فارسی
تطبیق داده شد. **اکانت daneshyar.web از طریق MCP.ai Basic وصل شد.** ورود OAuth
در Codex، وضعیت Connected/Active اکانت و خواندن فهرست ابزارهای MCP بررسی شدند.
وضعیت در `connection.json` و گزارش در `research/connection-verification.json` است.

## استفاده از مهارت‌ها

از پیام بعدی در همین پروژه، درخواست عادی بده یا نام مهارت را ذکر کن؛ برای مثال:

- `$ig-profile` یک بیوی پیشنهادی برای دانشیار بنویس.
- `$ig-caption` کپشن فارسی معرفی خدمات دانشیار را آماده کن.
- `$ig-reel` سناریوی معرفی خدمات و متن روی تصویر بنویس.
- `$ig-plan` برنامهٔ محتوایی هفتهٔ آینده را آماده کن.

| مهارت | کاربرد |
| --- | --- |
| `ig-profile` | بررسی و پیشنهاد متن و چیدمان پروفایل |
| `ig-caption` | کپشن و دعوت به اقدام |
| `ig-reel` | سناریو، شروع و زمان‌بندی تقریبی ریلز |
| `ig-carousel` | محتوا و طرح پست اسلایدی |
| `ig-story` | توالی استوری |
| `ig-plan` | برنامهٔ محتوا |
| `ig-repurpose` | تبدیل محتوای موجود به قالب‌های دیگر |
| `ig-human` | ویرایش طبیعی و روان متن |
| `ig-comment` | پیش‌نویس کامنت |
| `ig-reply` | پیش‌نویس پاسخ |
| `ig-dm` | پیش‌نویس دایرکت |
| `ig-viral` | تحقیق با دادهٔ واقعی و پروندهٔ ایده‌ها |
| `ig-audit` | تحلیل عملکرد با آمار واقعی ارائه‌شده |

راهنمای برند، خدمات، تماس و لحن در `brand/voice.md` است. مهارت‌ها پیش از تولید
محتوا این فایل و `skills/CODEX.md` را می‌خوانند. امتیازدهی انگلیسی ابزارهای همراه
معیار معتبر متن فارسی نیست؛ نیم‌فاصله در ابزار پاک‌سازی محلی حفظ می‌شود.

## نصب پروژه و بازسازی مسیرها

فایل‌های اصلی در `instagram/skills/` نگهداری می‌شوند. مسیرهای `.agents/skills/ig-*`
فقط junction محلی برای کشف مهارت‌ها توسط Codex هستند و وارد Git نمی‌شوند. پس از
انتقال پروژه یا checkout تازه، از ریشهٔ پروژه اجرا کن:

```powershell
powershell -NoProfile -File instagram/scripts/register-skills.ps1
```

این دستور تکرارپذیر است و مورد موجود نامرتبط را جایگزین نمی‌کند. اگر فهرست مهارت‌ها
تازه نشد، پروژه یا برنامه را دوباره باز کن. ابزارهای همراه فقط به Python 3 نیاز دارند؛
مسیر اجرا در هر `SKILL.md` نوشته شده است. خروجی‌های کاری در `instagram/state/` و
دارایی‌های محتوایی داخل همین پوشهٔ Instagram قرار می‌گیرند.

منبع: [Instagram Agent Skill](https://github.com/Jakeschincariol/instagram-agent-skill)،
مجوز MIT، نسخهٔ ثابت `d03c56bb598be770c60b201f94237e5d1a4268a6`.
مجوز در `skills/LICENSE`، فهرست منبع در `research/skill-upstream.json` و تغییرات
محلی در `skills/CODEX.md` ثبت شده‌اند. انتخاب این مجموعه به معنی شناسایی قطعی
پست شبکهٔ اجتماعی مورد اشارهٔ کاربر نیست.

## اتصال حساب

سرور `daneshyar_instagram` در تنظیمات پروژه ثبت و با OAuth وارد شده است. اتصال
اکانت `daneshyar.web` از ورود رسمی Instagram با واسط Composio انجام شد. دسترسی‌های
اطلاعات پایه، انتشار، کامنت، پیام و آمار تأیید شدند. فهرست واقعی سرور ۳۳ ابزار
(شامل ابزارهای عمومی سرویس و Instagram) برگرداند. هیچ پست یا پیام آزمایشی ارسال نشد.

بیو و عکس پروفایل از مرورگر واردشده قابل ویرایش‌اند؛ MCP انتخابی ابزار ویرایش آن‌ها
ندارد. صفحهٔ دسکتاپ Instagram تغییر لینک سایت را به برنامهٔ موبایل محدود می‌کند.
دایرکت تابع محدودیت‌های Meta و مجوزهای گفتگو است. پاسخ خودکار و مانیتورینگ پس‌زمینه
فعال نیستند. راهنمای ورود مجدد و بررسی اتصال در `connection-setup.md` است.

اگر ابزارهای MCP در همین چت ظاهر نشدند، در نوبت تازه بررسی کن و در صورت نیاز پروژه
را دوباره باز کن؛ بارگذاری فهرست ابزار با خود فرایند Codex با موفقیت آزمایش شد.

کاربر ابزار رایگان را ترجیح می‌دهد. گزینه‌های اتصال در `research/free-tools.md`
ثبت شده‌اند؛ مسیر MCP.ai Basic اکنون انتخاب و متصل شده، و گزینهٔ محلی Meta هنوز نصب
نشده است. امکانات Advanced پولی مثل فالو/آنفالو و شروع دایرکت جدید انتخاب نشده‌اند. Metricool
به‌عنوان افزونه موجود است، اما اکانت هدف در آن تأیید نشده و مسیر انتخابی فعلی نیست.
برای هزینه، مجوزها و قابلیت‌های هر سرویس، مستندات روز ارائه‌دهنده باید بررسی شود.

توکن‌ها و نشست‌ها فقط در فایل‌های محلی نادیده‌گرفته‌شده نگهداری می‌شوند؛ رمز،
کد ورود یا توکن را در چت و گزارش ثبت نکن.
