# بررسی گزینه‌های آماده اتصال اینستاگرام

این گزارش بررسی اولیه است. ترجیح جدید کاربر و گزینه‌های رایگان تازه در
[free-tools.md](free-tools.md) ثبت شده‌اند؛ Metricool دیگر مسیر پیش‌فرض نیست.

تاریخ بررسی: ۲۰۲۶-۱۱-۰۹. حساب هدف: `daneshyar.web`، از نوع Business به تأیید کاربر.

## نتیجه

انتخاب اولیه برای انتشار و آمار: **افزونه آماده Metricool**. برای دایرکت یا کامنت، قابلیت‌های
آن کافی نیست و باید اتصال API جداگانه پس از بررسی مجوزها آماده شود. اکنون هیچ اتصال تأییدشده‌ای
به اکانت وجود ندارد؛ تحقیق و پیشنهاد نصب به معنی نصب یا ورود موفق نیست.

| گزینه | وضعیت هنگام بررسی | کاربرد قابل اتکا در این مرحله |
| --- | --- | --- |
| Metricool | در فهرست افزونه‌ها موجود؛ نصب نشده | برندها، آمار و برنامه‌ریزی پست |
| Windsor.ai | در فهرست افزونه‌ها موجود؛ نصب نشده | متادیتای افزونه آمار و برخی عملیات انتشار/پاسخ را معرفی می‌کند؛ نوع دقیق عملیات اینستاگرام روی اکانت بررسی نشده |
| Supermetrics Marketing Agent | در فهرست افزونه‌ها موجود؛ نصب نشده | متادیتای افزونه انتشار/زمان‌بندی و پاسخ به کامنت را معرفی می‌کند؛ روی اکانت بررسی نشده |
| Canva | موجود؛ نصب نشده | طراحی محتوا؛ برای اتصال و مدیریت خود اکانت انتخاب نشد |
| William-Gao/instagram-mcp | پروژه عمومی؛ نصب نشده | نامزد اتصال مستقیم برای انتشار، کامنت و پیام با مجوزهای لازم |
| supercorp-ai/instagram-mcp | پروژه عمومی؛ نصب نشده | گزینه محدودتر برای ورود، خواندن مدیا و انتشار تک‌عکس |

وجود و وضعیت نصب افزونه‌ها با فهرست زنده افزونه‌های حساب بررسی شد. ادعاهای متادیتای آن‌ها،
مخصوصاً Windsor.ai و Supermetrics، به‌عنوان قابلیت عملیاتی تأییدشده روی این اکانت ثبت نشده‌اند.

## منابع بررسی‌شده

- [راهنمای اتصال Metricool](https://help.metricool.com/how-to-connect-metricools-mcp-with-chatgpt-0lrl3):
  برنامه‌ریز و آمار در MCP موجودند؛ Inbox، کامنت‌ها و چند بخش دیگر موجود نیستند.
- [پلن‌ها و محدودیت‌های Metricool MCP](https://help.metricool.com/mcp-limits-and-plan-requirements-h72jg):
  MCP با پلن Free هم در دسترس است؛ این به معنی حذف محدودیت پلن نیست.
- [اتصال سایر کلاینت‌ها به Metricool](https://help.metricool.com/how-to-connect-metricools-mcp-eqp9h):
  آدرس رسمی HTTP MCP برابر `https://ai.metricool.com/mcp` است. چون افزونه آماده موجود است،
  سرور تکراری در تنظیمات پروژه ثبت نشد.
- [William-Gao/instagram-mcp](https://github.com/William-Gao/instagram-mcp):
  README، فایل نمونه محیط و manifest بسته بررسی شدند. مجوز MIT و وضعیت Alpha در manifest است.
  کامیت بررسی‌شده: `d8e1adf7ae1cb071c490d0fca379386d020b6cd0`.
  ابزارهای پیام در README به مجوز Advanced Access وابسته‌اند. نام «profile» در فهرست ابزارها
  به خواندن اطلاعات اشاره دارد؛ ویرایش بیو/عکس از این بررسی اثبات نشد.
  کد کامل، وابستگی‌ها و رفتار شبکه هنوز ممیزی یا اجرا نشده‌اند.
- [supercorp-ai/instagram-mcp](https://github.com/supercorp-ai/instagram-mcp):
  README ابزارهای ورود، فهرست مدیا و انتشار یک عکس را مستند می‌کند؛ پوشش آن از نامزد قبلی محدودتر است.
- [مستندات رسمی Meta در Postman](https://www.postman.com/meta/instagram/folder/1z5vxzu/instagram-api-with-instagram-login):
  حساب حرفه‌ای و مجوزهای جدا برای خواندن، انتشار، کامنت و پیام تعریف شده‌اند.
- [پیش‌نیازهای Send API در مجموعه رسمی Meta](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api?entity=request-23987686-3fe78620-2258-44b6-893f-42d76c7200d7):
  گیرنده باید پیش‌تر به حساب حرفه‌ای پیام داده باشد؛ این مسیر دایرکت عمومی بدون محدودیت نیست.

صفحات مستقیم `developers.facebook.com` در این بررسی خطای 429 داشتند. به‌همین دلیل از مجموعه
رسمی Meta در Postman هم استفاده شد. مسیر ورود نهایی برای یک Meta App تازه باید با داشبورد همان
اپ تطبیق داده شود؛ از نام متغیر یا README یک پروژه نتیجه نمی‌گیریم که همه مسیرهای جدید را پشتیبانی می‌کند.

## مهارت‌ها

در فهرست مهارت‌های موجود و جست‌وجوی محلی `SKILL.md`، مهارت اختصاصی مدیریت Instagram پیدا نشد.
مهارت‌های موجود مدیریت افزونه‌ها، کنترل ویندوز و ساخت تصویر برای بخش‌های مرتبط کافی‌اند؛
برای شروع مهارت تازه‌ای نصب نشد.
