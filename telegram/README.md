# Telegram — دانشیار

تمام فایل‌های اختصاصی اتصال و کانال تلگرام در این پوشه قرار دارند.

| مسیر | کاربرد |
| --- | --- |
| `channel-format.json` | قالب تأییدشده پیام‌ها و اطلاعات تماس |
| `AGENTS.md` | دستورالعمل استفاده از قالب در کارهای بعدی |
| `integration/` | MCP، ورود محلی، تنظیم امنیت و محیط Python |
| `content/2026-11-09/` | متن‌های منتشرشده، شناسه پست‌ها، عکس و سوابق تغییرات |
| `assets/` | تصویر تبلیغاتی کانال |
| `previews/` | تصاویر بررسی نمونه‌های PDF |
| `scripts/` | اسکریپت‌های اجرایی و تاریخچه عملیات |

کانال: https://t.me/daneshyar_samples

قالب ثابت هر پست:

1. عنوان کوتاه و متن فارسی خوانا؛ عنوان در صورت استفاده از HTML به‌صورت bold.
2. هشتگ‌های اصلی `#دانشیار` و `#خدمات_دانشگاهی` همراه هشتگ موضوعی.
3. خط جداکننده و راه‌های تماس در انتهای پیام: یک آیدی تلگرام، اینستاگرام `daneshyar.web`، آدرس اصلی سایت و ایمیل.
4. خط انتهایی با کاراکتر نامرئی U+2060 برای فاصله‌دادن زمان و علامت ویرایش تلگرام.

برای نمونه‌کارها، همان پست پین‌شده با عنوان «نمونه‌کارها» و پنج لینک دانلود تکی
استفاده می‌شود. فایل ZIP و پست‌های جداگانه نمونه‌ها جزو قالب فعلی نیستند.

برای ساخت متن با قالب مشترک:

```python
from channel_format import format_post

text = format_post("<b>عنوان پیام</b>\n\nمتن پیام", ["#نمونه_کار"])
# در زمان انتشار از parse_mode="html" استفاده شود.
```

راهنمای اتصال و تست در `integration/README.md` است. نشست اکانت در همان مسیر
محافظت‌شده ویندوز باقی می‌ماند؛ جابه‌جایی پوشه پروژه نیاز به ورود مجدد ندارد.
